# Карточки заказчиков

Один файл на компанию: `<компания>.md`. Только проверенные данные, которые пригодятся в статьях: чем компания занимается (производит сама или закупает), цены «от», сроки, адреса складов и офисов, гарантии, сертификаты, отличия от конкурентов, сайт.

Навык `avtor-statey` ищет карточку здесь и передаёт её автору. Чего нет в карточке, в ТЗ и на сайте заказчика, автор не выдумывает: в тексте остаётся `[нужны данные: …]`.
