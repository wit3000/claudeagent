# ТЗ: Подключить реальные фото в карусель + чистовой вид

Итерация 11. Заказчик загрузил 4 фото в `landing/assets/photos/`:
`photo-1.png … photo-4.png` (1672×941, PNG). Довести карусель до чистового вида.

Файлы: `landing/index.html`, `landing/styles.css`. Не трогать: логику карусели в
`script.js` (кроме, при необходимости, расширения в массиве путей), фишку
котёнка-курсора, подсветку кнопок, шрифты, логотип. `python -m pytest -q` зелёный.

## 1. Расширение .png
Карусель ссылалась на `.jpg`, а файлы — `.png`. Поправить пути **везде**:
- `src` у 4 `<img class="slide">` в `index.html` → `assets/photos/photo-1.png` …
  `photo-4.png`.
- Если пути к фото продублированы в `script.js` (массив `PHOTOS`/подобное) —
  тоже на `.png`. Держать единый источник, без рассинхрона.

## 2. Первое фото грузим сразу (LCP)
У `photo-1` (первый, above-the-fold, активный слайд) убрать `loading="lazy"`
(поставить `loading="eager"` или без атрибута). У `photo-2..4` — `lazy` оставить.

## 3. Чистовой вид контейнера (под реальные фото)
Сейчас у `.hero__gallery` пунктирная рамка + штрих-фон (были плейсхолдером). Под
живые фото сделать аккуратно:
- Убрать пунктирную рамку и штрих-фон-подложку (или заменить на нейтральный
  тёмный фон-заглушку на время загрузки, напр. `var(--bg-tint)`), чтобы вокруг
  фото не было «строительной» рамки.
- Оставить/добавить: скругление `--radius` (как у других блоков), мягкую тень
  `--shadow-md`/`--shadow` для премиального вида, `overflow:hidden`.
- Пропорции 16:8 (или под 1672×941 ≈ 16:9 — можно оставить текущее
  `aspect-ratio`, `object-fit:cover` обрежет аккуратно; если хочется без обрезки
  — подогнать `aspect-ratio` ближе к 16:9, на выбор, задокументировать).
- Фото не должны выглядеть «вставленными в рамку-заглушку».

## 4. Не трогать
Тайминги карусели (2с/2с), поведение по наведению, тач-фолбэк, фишку курсора,
кнопки, шрифты. Адаптив (320/768/1440) без горизонтального скролла.

## 5. Критерии приёмки
- [ ] Карусель показывает реальные `photo-1..4.png`; пути `.png` везде
      согласованы (HTML и, если есть, JS).
- [ ] Первый слайд грузится eager, остальные lazy.
- [ ] Контейнер галереи без плейсхолдер-рамки/штриховки: скругление + мягкая
      тень, фото смотрятся чисто и премиально.
- [ ] Тайминги/поведение карусели не изменены; фишка курсора и кнопки целы;
      адаптив без горизонтального скролла.
- [ ] `python -m pytest -q` зелёный; `node --check script.js` ок; консоль чистая.
- [ ] Саморевью `code-review` пройдено.

## Примечание (вне этого ТЗ — для заказчика)
PNG тяжёлые (~1.6–2 МБ каждый, ~7.4 МБ на 4). Для прод-скорости их стоит
пережать (JPG/WebP, ресайз под ~1600px). Это отдельное решение заказчика; в
этой итерации подключаем как есть.
