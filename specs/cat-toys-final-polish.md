# ТЗ: Финальный визуальный полиш лендинга «Хулимяо»

Итерация 7 (финальная косметика). Заказчик: «сделай красиво — плавные шрифты и
контуры, объём, мягкие тени, согласованные цвета». Это **чисто визуальная
CSS-задача** — обязательно вызвать скилл `web-visual-polish` и следовать его
принципам (мягкие тени ≤2 на элемент, дисциплина весов, читаемость, контраст,
`:focus-visible`, `prefers-reduced-motion`).

**ТОЛЬКО CSS** (`landing/styles.css`). Не трогать: HTML/SVG/JS, разметку,
тексты, `@font-face`, картинку-лого, фишку котёнка-курсора и её анимации/логику,
подсветку кнопок. Ветка `claude/pupa-lupa-agents-nw54ho`. `python -m pytest -q`
зелёный.

## Что «причесать» (в рамках существующих стилей)

1. **Согласованная палитра.** Свести используемые цвета к единой системе
   токенов в `:root` (бренд-оранжевый, тёмный, кремовые, muted, семантические
   для бейджа экономии). Убрать разнобойные хардкод-хексы, где они дублируют
   существующие токены — заменить на `var(--...)`. Не вводить новый акцент,
   держать фирменную оранжево-кремовую гамму.

2. **Плавные контуры и объём.** Единая шкала радиусов (карточки/кнопки/бейджи/
   поля), аккуратные скругления. Мягкие тени — согласованные по глубине
   (карточки — средняя, мелкие элементы — лёгкая, поднятые — крупная), не более
   двух теней на элемент, тёмная непрозрачность ≤0.12. Убрать жёсткие/резкие
   тени, если попадутся.

3. **Типографика.** Плавная, читаемая иерархия на Commissioner: базовый текст —
   ExtraLight, заголовки/кнопки/бейджи — свои веса (уже есть). Проверить
   межстрочные, размеры, `letter-spacing` у крупных заголовков; выровнять
   вертикальные ритмы/отступы по единой шкале. Ограничить длину строки
   основного текста для читаемости, если можно без правки разметки.

4. **Состояния и переходы.** Hover/focus/active кнопок и ссылок — согласованные,
   плавные (переходы конкретных свойств, не `transition: all`), видимый
   `:focus-visible`. Не трогать анимации котёнка-курсора и подсветку лазером.

5. **Согласованность отступов.** Привести паддинги секций/карточек/контейнеров
   к единой шкале (4/8/12/16/24/32/48), убрать случайные значения.

## Границы (важно)
- Логотип-текст `.logo-word` (размер/объём/цвет из прошлой итерации) —
  трогать только если объём/тень явно не в общей системе; иначе оставить.
- Не менять поведение, DOM, тексты, доступность (ARIA), не прятать контент.
- Не переписывать CSS целиком без нужды — точечная гармонизация.

## Критерии приёмки
- [ ] Цвета сведены к токенам `:root`, дублирующие хардкоды заменены на `var()`;
      гамма согласована (оранжево-кремовая, один акцент).
- [ ] Радиусы, тени и отступы приведены к единым шкалам; тени мягкие (≤2,
      непрозрачность ≤0.12).
- [ ] Типографика плавная и читаемая; контраст основного текста ≥ AA.
- [ ] Состояния hover/focus/active согласованы; `:focus-visible` виден; нет
      `transition: all`; есть `prefers-reduced-motion`.
- [ ] Изменён только `landing/styles.css`; HTML/JS/SVG/шрифты не тронуты.
- [ ] Фишка котёнка-курсора, подсветка кнопок, картинка-лого, адаптив
      (320/768/1440) — целы, без горизонтального скролла.
- [ ] `python -m pytest -q` зелёный; `web-visual-polish` и `code-review`
      пройдены, находки разобраны.
