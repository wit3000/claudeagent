# ТЗ: Логотип «Хулимяо» — крупнее + аккуратный объём и мягкие тени

Итерация 4. Заказчик: цвет ок, но не хватает объёма и мягких теней, и надо
крупнее. ВНИМАНИЕ: НЕ возвращать старый «кирпич» (8-слойная тёмная экструзия +
градиент-клип) — объём должен быть деликатный, в фирменной оранжевой гамме,
буквы остаются яркими и читаемыми.

Файл: `landing/styles.css`, только `.logo-word` (и, если нужно, `.logo-mark`
размер). **Только CSS** — это задача под скилл `web-visual-polish`, вызови его и
следуй его принципам (мягкие тени, дисциплина, читаемость). HTML/SVG/JS не
трогать.

## Что сделать

1. **Крупнее.** Увеличить `font-size` логотипа: было `clamp(2.8rem, 8vw, 5rem)`
   → сделать `clamp(3.4rem, 10vw, 6.5rem)` (подобрать так, чтобы на десктопе
   было заметно крупнее, а на мобиле ≤360px не вылезало за экран и не ломало
   вёрстку — проверить).

2. **Аккуратный объём (soft 3D), НЕ кирпич.** Добавить короткую мягкую
   экструзию в тёмно-оранжевом (не в чёрном!) + одну мягкую размытую тень.
   Ориентир (подобрать по вкусу, но в этом духе):
   ```css
   text-shadow:
     0 1px 0  #E0721E,
     0 2px 0  #CC6519,
     0 3px 0  #B85916,
     0 4px 0  #A44E13,
     0 6px 10px rgba(58, 42, 30, .28),   /* мягкая опорная тень */
     0 12px 22px rgba(58, 42, 30, .20);  /* деликатное размытие */
   ```
   - Экструзия — 3–5 слоёв максимум, в градации оранжево-коричневого (от
     `--brand` темнее), чтобы читалось как объём буквы, а не грязь.
   - Заливка букв — прежний чистый `--brand` (#F5892E). Не возвращать
     градиент-клип.
   - Тонкую обводку `-webkit-text-stroke: 1px var(--brand-dark)` + `paint-order`
     оставить (для читаемости на кремовом hero).
   - Результат: яркие оранжевые буквы с лёгким «пряничным» объёмом и мягкой
     тенью — НЕ тёмная масса.

3. Капс, центр, верх, единственный `<h1>` — не менять.

## Не трогать
Знак-кот (SVG), `@font-face` Overdoze Sans, фолбэк-стек, шрифт текста
Commissioner, анимацию котёнка-курсора, подсветку кнопок, фолбэки, адаптив,
Python. `pytest -q` (через `python -m pytest`) зелёный.

## Критерии приёмки
- [ ] Логотип заметно крупнее на десктопе; на мобиле ≤360px не ломается/не
      вылезает.
- [ ] Есть мягкий объём (3–5 слоёв оранжево-коричневой экструзии) + мягкая
      размытая тень; НЕ чёрный «кирпич», буквы яркие и читаемые.
- [ ] Заливка — чистый оранжевый, без градиент-клипа.
- [ ] Изменён только CSS (`.logo-word` / размер `.logo-mark`); HTML/JS/SVG не
      тронуты.
- [ ] Прогнать `web-visual-polish` и саморевью `code-review`; починить находки.
