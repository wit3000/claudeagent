# ТЗ: Карусель — горизонтальный слайд справа налево, плавнее

Итерация 13. Заменить кроссфейд карусели на **горизонтальное пролистывание
справа налево** и сделать переход более плавным.

Файлы: `landing/styles.css` (переходы/классы слайдов), `landing/script.js`
(переключение классов + очистка). Не трогать: тайминги (2с/2с, первый показ на
2с), поведение по наведению/уходу, тач-фолбэк, фишку котёнка-курсора, подсветку
плиток/кнопок, фото, шрифты. `python -m pytest -q` зелёный.

## 1. Направление и вид
- **Справа налево:** новый (входящий) слайд появляется **справа** и въезжает к
  центру; текущий (уходящий) уезжает **влево** за край. Порядок листания
  прежний 1→2→3→4→1 (только forward).
- **Плавнее:** длительность перехода ~`0.7–0.9s`, мягкая кривая
  (напр. `cubic-bezier(.22,.61,.36,1)` или подобная ease-out/ease-in-out).
  Можно комбинировать сдвиг `translateX` с лёгким `opacity` для мягкости, но
  основной эффект — именно горизонтальный сдвиг, не просто фейд.

## 2. Реализация (ориентир — на выбор Лупы, но суть такая)
Слайды по-прежнему `position:absolute; inset:0` наложены. Три состояния:
- **По умолчанию (неактивный, «припаркован справа»):**
  `transform: translateX(100%); opacity: 0;`
- **Активный `.slide--active`:** `transform: translateX(0); opacity: 1;` (сверху
  по z-index).
- **Уходящий (напр. класс `.slide--leaving`/`.slide--prev`):**
  `transform: translateX(-100%); opacity: 0;` (уезжает влево, под активным по
  z-index).
- `transition` на `transform` и `opacity` с длительностью/кривой из §1.

JS `show(i)` при смене cur→next:
- пометить текущий как «уходящий» (уезжает влево), снять с него `--active`;
- на следующий повесить `--active` (въезжает справа, т.к. был припаркован справа);
- **очистить** класс «уходящий» с предыдущего уходящего после завершения
  перехода (по `transitionend` или таймауту ≈ длительности), чтобы он вернулся
  в дефолт «справа» и был готов к следующему въезду. Интервал 2с > перехода —
  наложений не будет, но очистку сделать аккуратно, без «прыжков».

## 3. Крайние случаи
- Возврат к первому слайду по `mouseleave`: сбросить к `photo-1` чисто, без
  затяжной «неправильной» анимации и без вспышки (допустимо мгновенно: временно
  снять transition / выставить состояния разом — на выбор, задокументировать).
- Первый показ на 2с (из прошлой итерации) сохранить.
- `prefers-reduced-motion: reduce`: переход мгновенный (без сдвига/анимации), как
  и раньше для слайдов — обновить медиазапрос под новые свойства (`transform`).
- z-index: активный над уходящим, чтобы въезд читался поверх ухода.

## 4. Критерии приёмки
- [ ] Слайды листаются горизонтально: входящий справа → в центр, уходящий → влево
      за край; порядок 1→2→3→4→1.
- [ ] Переход плавный (~0.7–0.9s, мягкая кривая), без рывков и без наложения
      двух «активных».
- [ ] Старт по наведению (первый на 2с), смена каждые 2с, стоп+возврат к первому
      по уходу — не сломаны; тач — статичный первый кадр.
- [ ] reduced-motion — мгновенное переключение без сдвига.
- [ ] Фишка котёнка-курсора, подсветка плиток/кнопок, адаптив — целы;
      горизонтального скролла страницы нет (слайды скрыты `overflow:hidden`).
- [ ] `python -m pytest -q` зелёный; `node --check script.js` ок; консоль чистая.
- [ ] Саморевью `code-review` пройдено, находки разобраны.
