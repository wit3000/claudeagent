# ТЗ: Котёнок моргает только в покое (не в беге)

Итерация 17. Правка одна. Заказчик: котёнок должен моргать **только когда
бездействует и курсор не двигается**; при движении курсора (бег) — **не моргать**.

Файл: `landing/styles.css`. Ничего кроме этого не трогать. `script.js` не трогать.
Ветка `claude/pupa-lupa-agents-nw54ho`. `python -m pytest -q` зелёный.

## Что сделать
- Убрать анимацию моргания в состоянии бега: правило
  `#cat.cat--running .cat-eye { animation: eye-blink ... }` (около строки 605) —
  удалить (или обнулить `animation: none`). При беге глаза открыты, не моргают.
- **Оставить** моргание в покое: `#cat.cat--sitting .cat-eye { animation:
  eye-blink 4s ... }` (около строки 710) — не трогать.
- Состояние прыжка (`cat--jumping`) и так без моргания — оставить как есть.
- Комментарий у `@keyframes eye-blink` («общий кейфрейм для бега и покоя»)
