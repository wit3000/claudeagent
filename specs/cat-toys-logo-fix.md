# ТЗ: Логотип «Хулимяо» — переделка шрифта, цвета, знак-кот + шрифт текста

Итерация 3. Заказчик забраковал текущий логотип: вместо чистого оранжевого с
мягкой тенью получилась тёмно-коричневая нечитаемая масса (виноваты тяжёлая
многослойная экструзия + градиент с `background-clip`). Плюс новые требования
по шрифтам и знаку-коту над названием.

Файлы: `landing/index.html`, `landing/styles.css`. Ветка
`claude/pupa-lupa-agents-nw54ho`. Не ломать: анимацию котёнка-курсора,
подсветку кнопок, фолбэки, `pytest -q` зелёный. Слои — по `LAYERS.md`.

Заменяет: логотип из `specs/cat-toys-revisions.md` п.2 (стиль/цвет/шрифт) и
шрифт из `specs/cat-toys-copy.md` п.4.

---

## 1. Шрифт основного текста — Commissioner ExtraLight

- Весь текст сайта (кроме логотипа) — **Commissioner**, начертание
  **ExtraLight (200)**. Есть на Google Fonts, с кириллицей.
- Подключить Google Fonts: семейство `Commissioner` с весами `200;400;600;700`
  (200 — базовый текст; более жирные оставить для кнопок, заголовков таблицы,
  бейджей — чтобы не терять читаемость и иерархию).
- Заменить токен `--font` в `:root`:
  `--font: "Commissioner", -apple-system, "Segoe UI", Roboto, sans-serif;`
  (сейчас там Nunito — убрать Nunito из подключения, если больше нигде не нужен).
- `body { font-weight: 200; }` как база; существующие `font-weight: 600/700/800`
  на кнопках/заголовках/бейджах — оставить (это осознанная иерархия).
- ⚠️ Заметка (не блокер): ExtraLight — тонкое начертание; на мелком тексте и
  светлом фоне следить за контрастом (AA). Если где-то совсем бледно —
  допустимо поднять базу до 300, но по умолчанию делаем 200 как просил заказчик.

## 2. Логотип: шрифт Overdoze Sans (самохостинг) + чистый цвет

### 2.1. Шрифт — Overdoze Sans через @font-face

- Overdoze Sans нет на Google Fonts — **самохостим файл**, который положит
  заказчик. Прописать `@font-face`:
  ```css
  @font-face {
    font-family: "Overdoze Sans";
    src: url("assets/fonts/overdoze-sans.woff2") format("woff2");
    font-weight: 400 900;
    font-display: swap;
  }
  ```
- Создать папку `landing/assets/fonts/` и положить туда файл-заглушку/README
  `TODO: положить overdoze-sans.woff2 (файл предоставляет заказчик)`.
  Лендинг **не выпускать в прод**, пока файла нет.
- `.logo-word` → `font-family: "Overdoze Sans", <кириллический фолбэк>`.
- ⚠️ **Крепкий фолбэк с кириллицей обязателен:** если в файле Overdoze не
  окажется кириллических глифов, браузер подставит фолбэк для «ХУЛИМЯО».
  Фолбэк-стек: `"Overdoze Sans", "Commissioner", "Arial Black", sans-serif`
  с `font-weight: 800` — чтобы название в любом случае осталось жирным и
  читаемым. (Можно вместо Commissioner подключить жирный дисплейный кириллик
  типа `Unbounded`/`Montserrat` 800 как фолбэк — на выбор Лупы, задокументировать.)

### 2.2. Цвет и объём — чистый оранжевый + мягкая тень (ГЛАВНОЕ)

Полностью **переписать** оформление `.logo-word`. Убрать:
- многослойную лесенку `text-shadow` (8 теней) — она дала «кирпич»;
- `background: linear-gradient` + `-webkit-background-clip: text` +
  `-webkit-text-fill-color: transparent` — из-за них заливка ушла в грязь;
- толстую `-webkit-text-stroke: 2px` — оставить максимум тонкую (см. ниже) или
  убрать совсем.

Сделать так:
- **Заливка — чистый фирменный оранжевый** `color: var(--brand)` (#F5892E).
  Никаких градиентов-клипов.
- **Мягкая тень** — одна-две, деликатно: например
  `text-shadow: 0 2px 0 #D9722340, 0 6px 14px rgba(58,42,30,.28);`
  (лёгкая опора снизу + мягкое размытие). Тени приглушённые, НЕ чёрный кирпич.
- **Контраст на светлом hero:** буквы оранжевые на кремовом фоне — проверить,
  что читаемо. Если мало контраста, добавить **тонкую** тёмную обводку
  `-webkit-text-stroke: 1px var(--brand-dark); paint-order: stroke fill;`
  (1px, не 2px) — только ради читаемости, не ради «объёма».
- Капс (`text-transform: uppercase`), по центру, вверху, единственный `<h1>`.
  Размер `clamp(2.8rem, 8vw, 5rem)`, `letter-spacing: .01em`, `line-height: 1`.
- Итог должен читаться как **яркое оранжевое название с мягкой тенью**, а не
  тёмно-коричневая масса. Это критерий приёмки.

## 3. Знак-кот над названием (inline-SVG по мотивам фото)

Заменить текущую маленькую оранжевую мордочку (`.logo-mark`) на **нового
кота по мотивам присланного фото** — рисуем как inline-SVG (внешних файлов нет).

Как выглядит (по референсу):
- **Пушистый длинношёрстный кот**, лежит/развалился, добродушный.
- Окрас: **серо-белый** — спина/голова/хвост серые с тёмным табби-рисунком
  (`#8A8F96` / темнее `#5C6169`), грудь/живот/лапы **белые** (`#F5F5F7`).
- Крупный **пушистый хвост**, кисточки шерсти по контуру (рваный мех).
- Мордочка: **зелёные глаза**, розовый нос, высунутый язычок (мило), розовые
  подушечки лап, розоватые внутренние уши.
- Обводка контура тёмная тонкая (`#2B2B30`), стиль мультяшный-клипарт.
- Компоновка: знак **над** названием, по центру, в самом верху `<header>`
  (внутри `.logo`, как сейчас). Размер знака ~96–120px (крупнее прежней 72px,
  раз это теперь главный визуал бренда). Весь лок-ап (знак + название)
  кликабелен `<a href="#top">`, не мешает слою курсора.
- Стиль держать в 4–6 цветах, чтобы читался мелким; на мобиле чуть меньше.
- Это «по мотивам», не пиксель-в-пиксель — точная трассировка фото не требуется.

> Примечание: если позже заказчик даст растровый файл логотипа, знак легко
> заменить на `<img>` — но сейчас делаем SVG, чтобы лендинг был самодостаточным.

## 4. Критерии приёмки

- [ ] Весь текст (кроме логотипа) — Commissioner, база вес 200 (ExtraLight);
      кнопки/заголовки/бейджи сохранили жирность и иерархию; кириллица ок.
- [ ] Nunito убран из подключения (если больше не используется).
- [ ] Логотип: подключён `@font-face` Overdoze Sans на `assets/fonts/
      overdoze-sans.woff2`; папка создана, файл помечен TODO (предоставит
      заказчик); есть крепкий кириллический фолбэк — без файла название
      «ХУЛИМЯО» всё равно жирное и читаемое.
- [ ] Логотип-текст: **чистый оранжевый (#F5892E) + мягкая тень**, без
      многослойной экструзии и без градиент-клипа; читается ярко и чисто
      (не тёмно-коричневая масса). Капс, по центру, вверху, единственный `<h1>`.
- [ ] Над названием — новый знак-кот (серо-белый пушистый, зелёные глаза,
      язычок) как inline-SVG, по центру, крупнее прежнего; лок-ап кликабелен.
- [ ] Ничего не сломано: анимация котёнка-курсора, подсветка кнопок, фолбэки
      (touch/reduced-motion), адаптив ≤360px; `pytest -q` зелёный;
      `node --check script.js` ок; нет ошибок в консоли.
- [ ] Прогнать саморевью `code-review`, починить находки до коммита.

## 5. Оговорка по проверке
Скриншот в браузере из окружения снять нельзя (нет headless-браузера). После
пуша Пупа обновит живой предпросмотр-артефакт; заказчик смотрит глазами. В
предпросмотре Overdoze Sans не отрисуется (нет файла) — там будет виден
**фолбэк**; это ожидаемо, оценивать цвет/тень/знак-кота, а не конкретный шрифт
логотипа.
