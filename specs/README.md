# specs/ — почтовый ящик между Пупой и Лупой

Здесь лежат ТЗ. Пупа (аналитик) пишет сюда файлы `<краткое-имя>.md` по
шаблону скилла `write-spec`, Лупа (кодер) читает их и реализует.

Заодно это история решений: почему сделали так, а не иначе.

Передача задачи кодеру: `@lupa реализуй specs/<имя>.md`.
