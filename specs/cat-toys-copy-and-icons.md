## 1. Моргание котёнка-курсора не видно — починить

Симптом: котёнок **не моргает** (клиент не видит моргания), хотя анимация
задумана в беге и в покое.

- Диагноз (проверить): глаза — это группы `<g class="cat-eye cat-eye--l/--r">`
  внутри `#cat` SVG; моргание сделано через `@keyframes eye-blink`
  (`scaleY`) с `transform-box: fill-box; transform-origin: 50% 50%` на группе.
  На `<g>`-элементах `transform-box: fill-box` в ряде браузеров даёт нерабочий/
  нулевой bbox → `scaleY` фактически не применяется, глаз не закрывается.
- **Требование:** сделать моргание НАДЁЖНО ВИДИМЫМ и в `.cat--running`, и в
  `.cat--sitting`. Способ на выбор Лупы, но устойчивый, например:
  - задать глазам `transform-box: view-box` и `transform-origin` в координатах
    viewBox по центру каждого глаза (левый ~`65px 46px`, правый ~`83px 46px`),
    затем `transform: scaleY()` в keyframes; **или**
  - анимировать «веко» — прямоугольник/эллипс цвета мордочки (`#FFE7D1`),
    накрывающий глаз, через `scaleY` от 0 (открыт) к 1 (закрыт); **или**
  - иной способ, гарантированно закрывающий глаз.
- Моргание должно **читаться глазом**: глаз полностью закрывается на ~120–180мс,
  периодичность ~2–3с (в беге можно чуть чаще). Радужка+зрачок+блик закрываются
  вместе.
- reduced-motion: в этом режиме моргание выключено (глаза открыты) — сохранить.
- Проверить, что не сломаны бег/прыжок/посадка и что глаза не «съезжают».

## 2. Тексты — правки (вставлять ДОСЛОВНО, с `&nbsp;` как указано)

### 2.1. Hero — сократить подзаголовок
Заменить весь текст `.hero__lead`:
- было: «Игрушки для кошек из натуральных материалов — прочные и дешевле, чем в магазине»
- стало (дословно): `Игрушки для&nbsp;котят всех возрастов`
- Показать **заглавными**: добавить в CSS `.hero__lead { text-transform: uppercase; }`
  (в DOM оставить обычный регистр — для скринридеров). Остальные стили
  `.hero__lead` не менять.

### 2.2. Убрать «офлайн-магазин» → просто «магазин»
Во всех местах заменить формулировки про офлайн на «магазин»:
- `.hero__usp` буллет: «Цена ниже, чем в&nbsp;офлайн-магазине» →
  `Цена ниже, чем в&nbsp;магазине`
- Заголовок блока цен: «Наша цена vs&nbsp;офлайн-магазин» →
  `Наша цена vs&nbsp;магазин`
- Лид блока цен: «…цена ниже, чем на&nbsp;полке в&nbsp;офлайне.» →
  «…цена ниже, чем на&nbsp;полке в&nbsp;магазине.»
- Заголовок колонки таблицы: «В&nbsp;офлайне» → `В&nbsp;магазине`
- Проверить, не осталось ли слова «офлайн» где-то ещё — убрать везде.

### 2.3. Блок «доверие» — убрать нейро-штампы
- Заголовок: «Натуральные материалы&nbsp;— это&nbsp;не&nbsp;просто слова» →
  `Натуральные материалы` (убрать хвост «— это не просто слова»).
- Последнее предложение абзаца «Прочная сборка держит активную игру
  и&nbsp;не&nbsp;лохматится за&nbsp;неделю.» — заменить на человеческое
  (дословно): `Сшито и&nbsp;склеено на&nbsp;совесть: выдержит азартные
  догонялки и&nbsp;охоту, не&nbsp;расползётся и&nbsp;не&nbsp;облысеет через
  неделю.`
- Остальную часть абзаца («Мы выбираем безопасные для животных материалы:
  натуральный джут, хлопок, дерево и нетоксичные красители. Ничего, что
  навредит котику, если он решит попробовать игрушку на зуб.») — оставить как есть.

## 3. Иконки игрушек — сделать стильно

Текущие иконки категорий (в `.card__media` — удочка, пирамидка, когтеточка,
мышка, автоигрушка) слишком **топорные/схематичные** (тонкие палочки, примитив).
Переработать в **аккуратный, стильный, единый икон-сет**:

- Единый визуальный стиль на все 5: **заливка мягкими фигурами** (а не
  тонкие линии-палки), скруглённые формы, дружелюбный «мультяшный» вид.
- Палитра — фирменная: `--brand #F5892E`, `--cream #FFE7D1`, `--cream-2 #FFC79A`,
  `--brand-dark #3A2A1E`, розовый нос-акцент `#E8859A` где уместно. 2–3 цвета на
  иконку, читаемо на кремовом круге `.card__media`.
- Одинаковая «тяжесть»/масштаб/отступы у всех пяти, чтобы сет смотрелся ровно.
- Узнаваемость: удочка-дразнилка (с пёрышком/помпоном), пирамидка (кольца
  на штырьке), когтеточка (столбик с обмоткой + основание), мышка (тельце,
  ушко, хвост), автоматическая игрушка (шар/диск с лучиком или кнопкой).
- Остаются inline-SVG (без внешних файлов), лёгкие. `viewBox="0 0 64 64"`,
  вписаны в текущий контейнер `.card__media svg { width:48px; height:48px }`.
- `aria-label`/`role="img"` на `.card__media` оставить (тексты подписей —
  прежние).
- (Опционально, если по ходу видно, что выбиваются) — можно так же освежить
  3 иконки в блоке «Почему Хулимяо», но приоритет — 5 иконок игрушек.

Это иллюстративная работа в SVG (HTML), НЕ под скилл web-visual-polish.
