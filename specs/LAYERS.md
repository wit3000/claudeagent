# LAYERS.md — разбор лендинга «Хулимяо» по слоям HTML / CSS / JS

Сопроводительный разбор к `specs/cat-toys-landing.md`. Задаёт границы
ответственности: что за что отвечает и где чему НЕ место. Примеры —
конкретные, из ТЗ.

Общий принцип: **HTML** — структура и контент, **CSS** — вид и «глупые»
анимации по классам, **JS** — состояние, координаты и переключение классов.
Данные (`CONTACTS`, `PRICES`, `IDLE_MS`) живут в JS-конфиге, а не размазаны
по разметке.

---

## HTML (`landing/index.html`) — структура и контент

Отвечает за: семантический каркас, статический контент, точки крепления для
CSS/JS. Никакой логики, никаких инлайн-стилей и `onclick`.

Конкретно из ТЗ:

- **Каркас 7 секций** (п. 2.1): `<header>` (hero), `<main>` с
  `<section id="categories">`, `<section id="usp">`,
  `<section id="prices">`, `<section id="about">`, `<section id="contacts">`,
  и `<footer>`. Один `<h1>` с `Хулимяо`, дальше `h2/h3`.
- **Hero-контент:** заголовок, подзаголовок-слоган
  («Натуральные игрушки для кошек — прочные и дешевле, чем в магазине»),
  две кнопки-ссылки CTA.
- **5 карточек категорий** (Удочки-дразнилки, Пирамидки, Когтеточки, Мышки,
  Автоматические игрушки) — статичная разметка `<article class="card">` с
  заголовком, описанием и `<img alt="...">`/SVG-плейсхолдером.
- **Три УТП-блока** (натуральные материалы / прочность / цена) — статичный
  текст + иконки.
- **CTA-ссылки** — именно `<a>` с реальными `href`:
  `href="https://wa.me/79161234567"`, `href="https://t.me/hulimyao"`,
  `href="tel:+79161234567"`, с `target="_blank" rel="noopener noreferrer"`
  для внешних. Значения приходят из `CONTACTS` (JS может их проставить/сверить,
  но базовый `href` — в разметке).
- **Контейнер блока цен:** пустой `<table>`/`<div id="price-table">`, который
  **наполняет JS** из `PRICES`. В HTML — только заголовки колонок
  («Наша цена», «В офлайне», «Экономия») и приписка «Цены указаны для примера…».
- **Слои фишки курсора** — два декоративных узла у конца `<body>`:
  `<div id="laser-dot" aria-hidden="true"></div>` и
  `<div id="cat" aria-hidden="true"></div>` (или инлайн-`<svg>` котёнка внутри).
  Пустые контейнеры — их поведение целиком на CSS+JS.
- **Доступность (п. 2.7):** семантические теги, `alt` у картинок,
  `aria-label` у иконок-ссылок, `aria-hidden="true"` на слое курсора.

НЕ в HTML: цвета/размеры (→ CSS), координаты котёнка, вычисление экономии,
обработчики (→ JS).

## CSS (`landing/styles.css`) — вид и декларативные анимации

Отвечает за: раскладку, адаптив, оформление, и все анимации, которые можно
описать классом/`@keyframes` без вычислений в реальном времени.

Конкретно из ТЗ:

- **Раскладка и адаптив (п. 2.7):** grid/flex для сетки 5 карточек,
  брейкпоинты (≤480 мобайл, планшет, десктоп), тап-цели кнопок `min-height:44px`.
- **Скрытие системного курсора** на десктопе: `body { cursor: none; }`
  (включается только когда фича активна — класс на `<body>` ставит JS).
- **Лазерная точка** (п. 2.2): внешний вид — `radial-gradient` красного
  свечения, `~14px`, `border-radius:50%`, `filter: blur(...)`, пульсация через
  `@keyframes pulse`. Обязательно `position: fixed`, `pointer-events: none`,
  `will-change: transform`, высокий `z-index`.
- **Котёнок — внешний вид и «глупые» анимации:** `@keyframes` для бега (лапки/
  подпрыгивание) и для довольного idle (моргание, хвост). Флип по направлению —
  через класс `.cat--flip { transform: scaleX(-1) }` (класс вешает JS).
  Прыжок — либо CSS-`transition`/`@keyframes jump` длительностью `JUMP_MS`,
  запускаемый добавлением класса `.cat--jumping` (триггерит JS).
- **Состояния котёнка как модификаторы-классы:** `.cat--running`,
  `.cat--jumping`, `.cat--sitting` — CSS описывает, как каждое выглядит; **JS
  только переключает** эти классы.
- **Позиционирование через transform:** CSS задаёт, что точка/котёнок двигаются
  `transform: translate3d()` (значения пишет JS), а не `top/left`.
- **`prefers-reduced-motion: reduce`** (п. 2.5): медиазапрос, который
  отключает `@keyframes` бега/прыжка/пульсации.
- **Оформление блока цен, карточек, кнопок, футера, контраст AA** (п. 2.7).

НЕ в CSS: конкретные X/Y координаты курсора, порог `IDLE_MS`, решение
«бежать или прыгать», наполнение таблицы.

## JS (`landing/script.js`) — состояние, координаты, переключение

Отвечает за: конфиг/данные, отслеживание курсора, машину состояний
`MOVING/IDLE`, покадровое движение и переключение CSS-классов, наполнение
таблицы цен, фолбэки.

Конкретно из ТЗ:

- **Конфиг и данные в одном месте** (крит. приёмки): константы `IDLE_MS=400`,
  `CHASE_EASE≈0.15`, `DOT_SIZE`, `CAT_SIZE`, `JUMP_MS`, `Z_INDEX`; объекты
  `CONTACTS` (phone/whatsapp/telegram) и массив `PRICES`.
- **Наполнение блока цен (п. 2.3):** пройти по `PRICES`, для каждой позиции
  посчитать `saveRub = offline - ours`, `savePct = round((offline-ours)/offline*100)`
  и отрендерить строки в `#price-table`. Цифры **не хардкодить в разметке**.
- **Отслеживание курсора:** слушатель `mousemove` → сохранять последние
  координаты и `lastMoveTs`. Таймер/проверка в loop: если
  `now - lastMoveTs > IDLE_MS` → состояние `IDLE`, иначе `MOVING`.
- **Единый `requestAnimationFrame`-loop** (п. 2.2): точка = мгновенно в
  координаты курсора (`translate3d`); котёнок — lerp к цели на `CHASE_EASE`
  каждый кадр («бежит следом»). Определять знак `dx` → вешать/снимать
  `.cat--flip`.
- **Переходы машины состояний:**
  - `MOVING → IDLE`: снять `.cat--running`, добавить `.cat--jumping`, по
    завершении (`JUMP_MS`) — `.cat--sitting`, точку «спрятать под лапами».
  - `IDLE → MOVING`: вернуть точку, снять `.cat--sitting`, добавить
    `.cat--running`.
- **Фолбэки (п. 2.5) — целиком на JS:**
  - `matchMedia('(pointer: fine)')` — на touch/мобиле **не активировать**
    фичу вообще: не ставить класс на `<body>`, не вешать `mousemove`, оставить
    нативный курсор.
  - `mouseleave`/`mouseenter` документа — прятать/возвращать точку и котёнка.
  - учёт скролла/ресайза при пересчёте позиций; отсутствие утечек слушателей;
    не гонять loop вхолостую, когда `IDLE` и анимации доиграли.
  - при желании — увеличивать точку над кликабельным (по `mouseover` на
    `a,button`).
- **Проставить/сверить `href` кнопок из `CONTACTS`** (если решено генерить их
  из конфига), включая префилл-текст WhatsApp.

НЕ в JS: инлайн-стили внешнего вида (цвета, размеры, тени — это CSS через
классы); статические тексты секций (это HTML). JS двигает `transform` и
дёргает классы — оформление этих классов остаётся в CSS.

## Быстрая таблица «фича → слои»

| Фича из ТЗ | HTML | CSS | JS |
|---|---|---|---|
| Лазерная точка | пустой `#laser-dot` | вид, свечение, пульс, `fixed`, `pointer-events:none` | координаты (`translate3d`) |

| Тач/мобайл фолбэк | — | `cursor:auto` по умолчанию | `matchMedia('(pointer:fine)')`, не активировать |
| reduced-motion | — | медиазапрос отключает `@keyframes` | (опц.) не запускать анимации |
