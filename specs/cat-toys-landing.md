# ТЗ: Лендинг-одностраничник — игрушки для кошек с курсором-«лазером» и котёнком

## 0. Контекст

Клиент — **производитель игрушек для кошек** (удочки-дразнилки, пирамидки,
когтеточки, мышки, автоматические игрушки). Нужен продающий
лендинг-одностраничник.

УТП (три кита, вокруг которых крутится вся страница):
1. **Только натуральные и безопасные для животных материалы** — ничего
   токсичного, кошке не навредит.
2. **Высокая прочность и долговечность** — не разгрызёт за неделю.
3. **Цена ниже, чем в офлайн-магазинах.**

Целевое действие: посетитель пишет в мессенджер или звонит (лид-ген без
корзины и без бэкенда).

**Ключевая фишка (маркетинговый крючок):** кастомный курсор. Пока курсор
движется — он отрисован как **красная лазерная точка**, и за ней **бегает
мультяшный рыжий котёнок**. Как только курсор **останавливается** — котёнок
**прыгает на точку, накрывает её лапками и сидит довольный**. Это должно
работать плавно и не мешать пользоваться страницей (кликам, ссылкам, форме).

Технически это **статический сайт**: HTML + CSS + чистый JS (без фреймворков,
без сборщика). Один HTML-файл + подключённые ассеты. Хостится на любой статике
(GitHub Pages / Netlify / просто отдать заказчику папку).

Репозиторий: https://github.com/wit3000/claudeagent
Ветка для разработки: `claude/pupa-lupa-agents-nw54ho`
Складывать лендинг в папку `landing/` в корне репозитория (отдельно от
питоновского сервиса — они не связаны).

### 2.2. КЛЮЧЕВАЯ ФИШКА — курсор-лазер + котёнок

Это гвоздь программы. Расписываю поведение детально, чтобы не додумывать.

**Состояния:**
- `MOVING` — курсор движется (были события `mousemove` за последние ~120 мс).
- `IDLE` — курсор остановился (нет `mousemove` дольше порога `IDLE_MS`,
  дефолт **400 мс**).

**Отрисовка курсора:**
- Нативный системный курсор скрыть на десктопе: `body { cursor: none; }`
  (только когда фича активна — см. фолбэки в 2.5).
- **Лазерная точка** — небольшой светящийся красный кружок (radial-gradient,
  ~12–16 px, свечение/blur, лёгкая пульсация), позиция = координаты курсора.
  Элемент абсолютный/фиксированный, `pointer-events: none` — **не должен
  перехватывать клики**.
- **Котёнок** — мультяшный рыжий котёнок, отдельный элемент рядом с точкой.

**Поведение в `MOVING`:**
- Точка следует за курсором **мгновенно** (по фактическим координатам).
- Котёнок **догоняет** точку с задержкой (easing / lerp: позиция котёнка
  каждый кадр приближается к цели на коэффициент `CHASE_EASE` ≈ 0.12–0.18).
  Визуально — «бежит следом».
- Котёнок **повёрнут в сторону движения** (флип по X в зависимости от знака
  dx: бежит влево — смотрит влево, вправо — вправо).
- Пока бежит — анимация бега (спрайт/кадры или CSS-анимация лапок/подпрыгивания).

**Переход `MOVING → IDLE`:**
- Курсор стоит `IDLE_MS` мс → котёнок **допрыгивает** до точки (короткая
  анимация прыжка ~250–350 мс, дуга вверх-вниз), приземляется на точку,
  **накрывает её лапками** (точка визуально «поймана» — притухает/прячется под
  лапами) и переходит в **довольную сидячую позу** (можно лёгкий idle-луп:
  моргание / дёрганье хвостом / «мурчание»).

**Переход `IDLE → MOVING`:**
- Как только снова `mousemove` — котёнок «отпускает» точку (точка снова
  загорается), встаёт и опять бежит следом. Без резких телепортов.

**Технические требования:**
- Анимация позиций — через `requestAnimationFrame`, не через `setInterval`.
  Один общий animation loop.
- Координаты обновлять по последнему `mousemove` (throttle не обязателен, но
  тяжёлых вычислений в обработчике не делать).
- Всё, что рисует курсор/котёнка — `position: fixed`, высокий `z-index`,
  `pointer-events: none`, `will-change: transform`, двигать через
  `transform: translate3d(...)` (не `top/left`), чтобы не было лагов.
- Параметры вынести в конфиг вверху скрипта: `IDLE_MS`, `CHASE_EASE`,
  `DOT_SIZE`, `CAT_SIZE`, `JUMP_MS`, `Z_INDEX`.

**Ассет котёнка (см. также 2.6):**
- Нужны как минимум три состояния: **бег** (можно 1 кадр + CSS-«подпрыгивание»,
  либо 2–4 кадра), **прыжок**, **сидит-накрыл-лапками (довольный)**.
- Реализация на выбор Лупы, но задокументировать в коде:
  - вариант A — инлайн-SVG с CSS-анимацией (предпочтительно: масштабируется,
    красится, не тянет внешние файлы, легко флипается);
  - вариант B — спрайт-лист PNG + `background-position`.
- Стиль: мультяшный, рыжий (оранжевый + светлый живот), дружелюбная морда.
  Держать в 2–3 цветах, чтобы читался мелким.

### 2.3. Блок сравнения цен «Наша цена vs офлайн»

Заказчик подтвердил: показываем **сравнение с офлайн-магазином**.

- Таблица/две колонки на 3–5 популярных позиций (по одной из категорий):
  «Наша цена» vs «Средняя цена в офлайне», и строка/бейдж экономии («−30%»
  или «−X ₽»).
- **Цены — рандомные плейсхолдеры** (заказчик попросил вставить любые).
  Задать в JS/HTML-массиве `PRICES` с пометкой `TODO: подтвердить`.
  Использовать ровно эти значения:
  ```js
  const PRICES = [
    { item: "Удочка-дразнилка",        ours: 490,  offline: 790 },
    { item: "Пирамидка",               ours: 690,  offline: 1090 },
    { item: "Когтеточка",              ours: 1290, offline: 1990 },
    { item: "Мышка (набор 3 шт.)",     ours: 350,  offline: 590 },
    { item: "Автоматическая игрушка",  ours: 1990, offline: 2890 },
  ];
  ```
  Экономию (%/₽) **считать из этих чисел**, не хардкодить: экономия ₽ =
  `offline - ours`, % = `round((offline - ours) / offline * 100)`.
- Явная приписка мелким текстом: «Цены указаны для примера, актуальные —
  уточняйте в мессенджере» (цифры рандомные). Приписку легко убрать одной
  строкой, когда заказчик подтвердит реальные цены.
- Не выдумывать конкретные бренды офлайн-конкурентов — обезличенно
  «офлайн-магазин».

### 2.4. Целевое действие — мессенджер/звонок (без бэкенда)

- Кнопки-ссылки, никакой формы и серверной обработки:
  - **WhatsApp** → `WHATSAPP_URL` (`https://wa.me/...`), можно с
    префилл-текстом `?text=Здравствуйте!%20Интересуют%20игрушки%20для%20кошки`.
  - **Telegram** → `TELEGRAM_URL`.
  - **Позвонить** → `tel:PHONE`.
- Кнопки повторяются минимум дважды: в Hero и в финальном CTA-блоке. Можно
  добавить «липкую» кнопку мессенджера в углу на мобиле (floating action
  button), но она **не должна** перекрывать контент и должна корректно
  сосуществовать с фишкой курсора (на мобиле фишки курсора всё равно нет, см.
  2.5).
- Все внешние ссылки — `target="_blank"` + `rel="noopener noreferrer"`.

### 2.5. Крайние случаи и фолбэки (обязательно)

- **Тач-устройства / мобилки:** у них нет курсора. Фичу курсора-котёнка
  **полностью отключить** на touch/мобиле: определять
  `matchMedia('(pointer: fine)')` и/или отсутствие hover. При отключении —
  вернуть нативный курсор (`cursor: auto`), не рисовать точку/котёнка, не
  вешать `mousemove`-логику. Контент и кнопки работают как обычно.
- **`prefers-reduced-motion: reduce`:** уважать. При этой настройке —
  либо отключить котёнка совсем (оставить нативный курсор), либо убрать
  анимации бега/прыжка (котёнок статичен). Решение задокументировать.
- **Курсор ушёл за пределы окна** (`mouseleave` на документе): прятать точку и
  котёнка (или парковать у края), при `mouseenter` — плавно вернуть.
- **Ресайз окна / скролл:** позиции пересчитывать корректно (использовать
  клиентские координаты; при скролле точка остаётся под физическим курсором).
- **Производительность:** loop не должен грузить CPU в простое — когда `IDLE` и
  анимации доиграли, можно снижать активность (не гонять rAF вхолостую или
  гонять дёшево). Никаких утечек слушателей.
- **Курсор над интерактивными элементами** (ссылки, кнопки): клики и ховеры
  работают штатно (гарантируется `pointer-events: none` на слое курсора).
  Опционально: над кликабельным менять вид точки (например, чуть увеличить) —
  приятно, но не обязательно.
- **Пустые/незаполненные `TODO`-плейсхолдеры:** ссылки-заглушки не должны
  вести в никуда молча — если `WHATSAPP_URL` = плейсхолдер, кнопка либо
  видимо помечена, либо стоит `#` с явным `TODO`. В прод — только с реальными.

### 2.6. Ассеты и плейсхолдеры

- Фото товаров — плейсхолдеры (серые блоки с подписью категории или простые
  SVG-иконки). Не тащить чужие фото из интернета (авторские права). Оставить
  `TODO: заменить фото`.
- Иконки УТП/категорий — инлайн-SVG или один икон-набор, подключённый локально
  (не CDN, чтобы работало офлайн; если CDN — учесть, что доступен только
  разрешённый список, см. ограничения артефактов; для статики заказчику лучше
  локально).
- Котёнок и лазер — как в 2.2 (предпочтительно инлайн-SVG, свои).
- Шрифты — системный стек по умолчанию; если веб-шрифт, то только Google Fonts
  и с фолбэком.

### 2.7. Адаптив и доступность

- Полностью адаптивно: мобайл (≤480), планшет, десктоп. Проверить, что ничего
  не разъезжается, кнопки тапабельны (≥44px).
- Семантическая разметка: `header/main/section/footer`, один `h1`, осмысленные
  `h2/h3`, `alt` у изображений, `aria-label` у иконок-ссылок.
- Контраст текста — AA. Красная лазерная точка не должна конфликтовать с
  красным текстом кнопок (следить за читаемостью CTA).
- Слой курсора помечен `aria-hidden="true"` (декоративный).

## 3. Ограничения и зависимости

- **Без фреймворков и сборщиков.** Ванильный HTML/CSS/JS. Допустимо: один
  небольшой self-hosted шрифт/иконки. Никакого React/Vue/bundler.
- Никакого бэкенда, БД, серверной обработки форм. Всё статическое.
- Кросс-браузерность: свежие Chrome, Firefox, Safari, Edge (десктоп + мобайл).
- Не использовать чужие изображения/логотипы/бренды без прав. Всё спорное —
  плейсхолдер с `TODO`.
- Не изобретать сертификаты, ГОСТы, юрлица, отзывы реальных людей — если
  заказчик не дал, ставим нейтральные формулировки/плейсхолдеры.

## 4. Риски и цена

- **Стоимость: низкая.** Статический одностраничник, ноль платных сервисов,
  ноль хостинга с бэкендом. Мессенджер-ссылки бесплатны.
- **Главный риск — фишка курсора:** легко сделать лагающей или мешающей UX.
  Митигация: `transform`+`rAF`, `pointer-events:none`, обязательные фолбэки
  (touch, reduced-motion). Если бы фичу делали на тяжёлой физике/канвасе —
  было бы дороже и рискованнее; договорились на лёгкую DOM/SVG-реализацию.
- **Риск «пустого» УТП по цене** без реальных цифр — закрыт плейсхолдерами
  `PRICES` + припиской «цены для примера».
- **Ассеты (лого, фото, номера, название):** блокируют прод, но не разработку.
  Помечены `TODO`, лендинг собирается на заглушках.
- Дорогих/сомнительных путей нет. Отговаривать не от чего.
