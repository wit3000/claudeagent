# Фото игрушек для hero-карусели

Сюда заказчик кладёт **4 фотографии** игрушек «Хулимяо» для слайдера в
hero-блоке (поле «Фото игрушек Хулимяо»).

## Как назвать файлы (важно — под эти имена заточен код)

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

Порядок показа = по номеру (1 → 2 → 3 → 4 → снова 1).

## Формат

- Ожидается **JPG**. Если фото в **PNG** — назови `photo-1.png` … `photo-4.png`
  и скажи об этом (в коде поменяется расширение в одном месте — массив `PHOTOS`).
- Желательно одинаковое соотношение сторон (примерно горизонтальные, под
  контейнер 16:8) и разумный вес (≤300–500 КБ каждое), чтобы страница не
  тормозила.
