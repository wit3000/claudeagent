# Фото игрушек для hero-карусели

Здесь лежат **4 фотографии** игрушек «Хулимяо» для слайдера в hero-блоке
(поле «Фото игрушек Хулимяо»).

## Имена файлов (под них заточен код)

- `photo-1.png`
- `photo-2.png`
- `photo-3.png`
- `photo-4.png`

Порядок показа = по номеру (1 → 2 → 3 → 4 → снова 1). Пути к фото живут в одном
месте — в `src` тегов `<img class="slide">` в `index.html`; JS берёт слайды из
DOM (отдельного массива путей нет). При замене файлов правь расширение там.

## Формат

- Сейчас загружены **PNG** 1672×941 (≈16:9); контейнер галереи подогнан под
  `aspect-ratio: 16/9`, чтобы `object-fit: cover` не срезал заметную часть кадра.
- Желательно одинаковое соотношение сторон (горизонтальные, ~16:9).
- Вес: текущие PNG тяжёлые (~1.6–2 МБ). Для прод-скорости их стоит пережать
  (JPG/WebP, ресайз под ~1600px, ≤300–500 КБ каждое) — отдельное решение заказчика.
