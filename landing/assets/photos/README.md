# Фото игрушек для hero-карусели

Здесь лежат **4 фотографии** игрушек «Хулимяо» для слайдера в hero-блоке
(поле «Фото игрушек Хулимяо»).

## Имена файлов (под них заточен код)

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

Порядок показа = по номеру (1 → 2 → 3 → 4 → снова 1). Пути к фото живут в одном
месте — в `src` тегов `<img class="slide">` в `index.html`; JS берёт слайды из
DOM (отдельного массива путей нет). При замене файлов правь расширение там.

## Формат и оптимизация

- Файлы **оптимизированы**: JPG, ресайз до 1600px по ширине, quality 82,
  progressive. Итог ~80–170 КБ каждый (было ~1.6–2 МБ в PNG) — суммарно ~0.5 МБ
  вместо ~7.3 МБ, страница грузится быстро и слайды не «подмигивают».
- Исходные тяжёлые PNG удалены из рабочего дерева (при необходимости
  восстанавливаются из истории git).
- При замене фото: заливай горизонтальные ~16:9, прогоняй через ту же
  оптимизацию (JPG/WebP, ≤1600px, ≤~200 КБ), сохраняя имена `photo-1..4`.
