# Протокол фактчека

Цель: у каждого проверяемого утверждения в статье есть источник или видимый маркер. Ничего не исправляется молча и ничего не подтверждается по памяти.

## 1. Извлечь утверждения

Выпиши всё, что можно проверить:

- числа, даты, сроки, цены, тарифы, расстояния;
- названия организаций, сервисов, приложений, законов, ГОСТов;
- адреса, телефоны, режим работы;
- технические характеристики: размеры контейнера, грузоподъёмность, формат кода;
- утверждения о третьих сторонах: «РЖД запускает…», «GS1 присваивает…».

Оценки («быстро», «надёжно») — не факты, ими занимается стоп-лист.

## 2. Назначить статус

| Статус | Когда ставится | Что в тексте |
|---|---|---|
| `подтверждено` | есть URL страницы, на которой факт написан прямо | факт без маркера |
| `из ТЗ` | данные заказчика из ТЗ: адреса, своя деталь, условия. Если поиск включён, сверь с сайтом заказчика | факт без маркера. Если сайт заказчика говорит другое, укажи расхождение в «Требует внимания» |
| `опровергнуто` | источник показывает другое значение | верное значение с источником. Замена — в заметках: «было X → стало Y, URL» |
| `не проверено` | источник не нашёлся или поиск выключен | факт с маркером `[не проверено: <что именно>]`. Для цифр при включённом поиске этот статус не допускается — см. раздел 2а |

Маркер называет, что именно не проверено: `[не проверено: срок контейнерного поезда 5 суток]`, а не просто `[не проверено]`.

## 2а. Цифры: только подтверждённые

Каждая цифра в статье, кроме данных заказчика, до сдачи подтверждается источником с URL. Это сроки, температуры, интервалы, длительность работ, сроки службы, массы, доли, количества, даты.

1. **Сначала ищи, потом пиши.** Цифру не ставят в текст по памяти или «по практике» в расчёте проверить позже. Большинство таких данных есть в открытом доступе: делай не меньше трёх запросов разными формулировками, по-русски и по-английски, начиная с первичных источников (производитель, госорган, ГОСТ, закон).
2. **Источник должен говорить именно это.** Цифра подтверждена, если на странице она написана прямо и относится к тому же предмету. Время вакуумирования кондиционера не подтверждает время для холодильника, данные по одной модели — для всей марки.
3. **Не подтвердилась — цифры в тексте нет.** Замени её подтверждённым значением, перепиши фразу без числа (механика, условие: «за один визит мастера», «пока не установится вакуум») или удали фразу. Маркер `[не проверено: …]` для цифр при включённом поиске не оставляй: он перекладывает проверку на заказчика.
4. **Непервичный источник называй в тексте.** Оценка компании, исследование, данные другого производителя: «по оценке Liberty Home Guard, холодильники Bosch служат 14–19 лет».
5. **Не подтверждение:** память модели, «типичные значения», «по опыту мастеров» без источника, страницы конкурентов, форумы.
6. **Исключение — данные заказчика** (ТЗ, бриф, карточка, сайт): статус `из ТЗ`. Цены заказчика не придумываются и не подтягиваются из чужих прайсов.

Без веб-поиска цифры получают маркер `[не проверено: …]`, как и остальные внешние факты (раздел 4).

## 3. Приоритет источников

1. Источники, которые дал SEO-специалист в ТЗ.
2. Сайт заказчика — для фактов о самой компании: цены, склады, услуги, адреса.
3. Первичные источники: законы и нормативные акты, ГОСТ, официальные сайты организаций. Например, GS1 Russia для штрихкодов, ОАО «РЖД» для ж/д-перевозок.
4. Авторитетные отраслевые и новостные издания.

Не являются источниками:

- **страницы конкурентов** — кроме фактов о самих конкурентах;
- **память модели**. Если факт «известен», но URL нет, статус `не проверено`;
- агрегаторы, форумы, ответы на вопросы, сгенерированные тексты без автора.

## 4. Без веб-поиска

Если поиск выключен, любое внешнее утверждение получает статус `не проверено`. Исключение — данные `из ТЗ`.

Нельзя заменять источник словами «по моим данным», «как известно», «по общедоступной информации». Статья без поиска будет полна маркеров — так и задумано: пользователь увидит, что проверить.

## 5. Одна ссылка на факт

URL конкретной страницы, где написан факт, а не главная страница сайта.

- Плохо: `https://www.gs1ru.org`
- Хорошо: адрес страницы с вопросом о проверке штрихкода на gs1ru.org

## 6. Устаревание

Для цен, тарифов и сроков: если на странице источника есть дата, она должна быть не старше 12 месяцев от текущей даты. Старше — статус `не проверено (устарело)`, в маркере дата источника: `[не проверено: тариф за 1 т, источник от марта 2024]`.

## 7. Запись в заметки

Подраздел `### Факты и источники`, строка на факт:

```
- Контейнерный поезд Москва — Красноярск идёт около 5 суток — подтверждено — https://…
- Склад в Красноярске: Северное шоссе, 7А, стр. 8 — из ТЗ — https://… (сверено с сайтом заказчика)
- Срок авиадоставки 1–2 дня — не проверено — источник не найден
```

Все маркеры `[не проверено: …]` из текста дополнительно перечисляются в `### Требует внимания`.
