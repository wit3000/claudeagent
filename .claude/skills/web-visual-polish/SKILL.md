# Web visual polish

## Назначение

Улучшай внешний вид уже существующего веб-интерфейса: выстраивай типографику, палитру, отступы, мягкие тени, скругления, переходы и состояния. **Единственный изменяемый слой — CSS.** Поведение, DOM и доступность должны остаться прежними.

## Когда применять

Применяй навык автоматически по смыслу запроса, даже без явного упоминания имени навыка, когда пользователь просит сделать интерфейс красивее, стильнее, современнее, аккуратнее или добавить визуальный polish. Срабатывай также на просьбы улучшить тени, палитру, шрифты, spacing, hover/focus или responsive-внешний вид.

Не применяй навык как решение для новой функции, исправления JavaScript/TypeScript, изменения данных, API, маршрутов, поведения или DOM. Если запрос смешанный, выполни только визуальную CSS-часть и явно назови остальное вне границ навыка.

## Жёсткий контракт: только CSS

Перед редактированием найди реально подключённые CSS-источники и прочитай их. Разрешены только существующие подключённые файлы `.css`, `.module.css`, `.scss`, `.sass` или `.less`.

Нельзя создавать, изменять или удалять HTML, JSX, TSX, JavaScript, TypeScript, шаблоны, DOM, тексты, классы, `id`, `data-*`, `aria-*`, `name`, `role`, обработчики, состояние, API, маршруты, конфигурацию, зависимости, изображения, SVG, шрифты, CDN или inline-стили. Не добавляй HTML-классы ради дизайна. Если CSS-файла нет, не подключай его через HTML или конфигурацию: сообщи блокер и остановись.

Не маскируй логику стилями. Не используй для декоративного упрощения `display: none`, `visibility: hidden`, `opacity: 0`, `clip-path`, нулевые `height/width`, `pointer-events: none`, `outline: none`, перекрывающий `z-index`, изменение порядка или `overflow: hidden`. Не прячь важный контент на мобильном экране. Не добавляй новый текст через `content`.

## Рабочий порядок

1. Найди точку входа CSS и существующие селекторы.
2. Зафиксируй инварианты: DOM, тексты, состояния, размеры интерактивных областей и поведение.
3. Сохрани существующий брендовый акцент. Если согласованной палитры нет, используй токены ниже.
4. Добавь или переиспользуй токены; затем стилизуй основу, типографику и компоненты.
5. Оформи только уже существующие состояния `hover`, `focus-visible`, `active`, `disabled`, selected, error, loading, empty и notification.
6. Добавь адаптивные правила без скрытия контента.
7. Проверь diff и CSS-синтаксис до отчёта.

## Обязательная визуальная система

В существующем корневом селекторе (`:root` или текущая тема) используй единый набор токенов. Имена можно сопоставить существующей системе, значения и смысл сохраняй:

```css
:root {
  --color-bg: #f6f8fc;
  --color-surface: #ffffff;
  --color-surface-muted: #eef2f7;
  --color-text: #172033;
  --color-text-muted: #667085;
  --color-border: #d9e0ec;
  --color-accent: #4f46e5;
  --color-accent-hover: #4338ca;
  --color-on-accent: #ffffff;
  --color-success: #15803d;
  --color-warning: #b45309;
  --color-danger: #b91c1c;
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 18px;
  --radius-pill: 9999px;
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;
  --space-7: 48px;
  --shadow-sm: 0 2px 8px rgba(15, 23, 42, 0.06);
  --shadow-md: 0 8px 24px rgba(15, 23, 42, 0.08);
  --shadow-lg: 0 16px 40px rgba(15, 23, 42, 0.10);
  --focus-ring: 0 0 0 3px rgba(79, 70, 229, 0.24);
  --transition-fast: 160ms ease-out;
  --transition-base: 220ms ease-out;
}
```

### Палитра и доступность

- Не вводи больше одного основного акцентного цвета.
- Сохраняй существующие брендовые и семантические цвета, если они уже согласованы.
- Основной текст: контраст минимум `4.5:1`; крупный текст: минимум `3:1`.
- Цвет не может быть единственным сигналом ошибки, успеха или выбора; сохраняй существующий текст, значок или форму.
- Не используй `#000000` для основного текста на белом фоне и не делай градиент основным фоном.

### Типографика

Используй системный стек без внешней загрузки: `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.

- базовый текст: `16px / 1.5`, `font-weight: 400`;
- `h1`: `36px / 1.1`, `700`, `letter-spacing: -0.02em`;
- `h2`: `24px / 1.2`, `700`, `letter-spacing: -0.01em`;
- `h3`: `18px / 1.3`, `600`;
- подписи: `14px / 1.4`, `400`;
- кнопки: `14px / 1.2`, `600`;
- допустимые веса: только `400`, `500`, `600`, `700`;
- основной текст ограничивай `70ch`, если это возможно без изменения разметки;
- не используй больше четырёх размеров текста на одном экране.

### Тени, границы и радиусы

Карточки и панели: `--shadow-md`; малые контролы и поля: `--shadow-sm`; существующие явно поднятые панели: `--shadow-lg`. Размытие тени — минимум `8px`, непрозрачность тёмного компонента — максимум `0.10`, не более двух теней на элементе. Карточки используют `18px`, поля и кнопки `12px`, малые элементы `8px`, pill-бейджи `9999px`. Базовая граница — `1px solid var(--color-border)`.

### Переходы и состояния

Используй только переходы конкретных свойств: `background-color`, `border-color`, `color`, `box-shadow`, `transform`. **Никогда не используй `transition: all`.** Базовая длительность — `220ms ease-out`, быстрая — `160ms ease-out`. Hover может менять фон или тень; масштабирование — не более `1.02`; active — `translateY(1px)` или scale не меньше `0.99`. Сохрани или добавь видимый `:focus-visible` через `--focus-ring`; не убирай фокус. Не добавляй мигание, сильное свечение или бесконечные анимации.

При наличии переходов добавь:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    transition-duration: 0ms !important;
    animation-duration: 0ms !important;
    animation-iteration-count: 1 !important;
  }
}
```

`!important` здесь разрешён только для сокращения motion; в остальных местах не используй его без уже существующей необходимости.

### Отступы и адаптивность

Используй шкалу `4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`. Малые контролы: `8px 12px` или `10px 16px`; карточки: `24px`; связанные поля: `12px`; самостоятельные блоки: `24px` или `32px`. Отступ страницы: `16px` до `767px`, `24px` или `32px` от `768px`.

Проверь ширины `320px`, `768px` и `1440px`. На `320px` не допускай горизонтальной прокрутки, обрезки текста или выхода кнопок за контейнер. Основной текст не уменьшай ниже `16px`, важный контент не скрывай и не меняй порядок интерактивных элементов ради декора.

## Запрещённый объём работ

Не добавляй страницы, компоненты, функции, фильтры, поиск, формы, уведомления, авторизацию, серверную часть, иконки, иллюстрации, 3D, JavaScript-анимации, внешние ресурсы или новую логику состояния. Не переписывай весь CSS без необходимости, не удаляй правила без доказательства, не меняй семантику и ARIA.

## Проверка перед отчётом

Обязательно:

- просмотри список изменённых файлов и diff;
- подтверди, что изменены только подключённые CSS-файлы;
- проверь отсутствие изменений HTML/JS/TS/конфигурации/зависимостей и новых атрибутов;
- проверь повторное использование токенов, контраст, `:focus-visible`, отсутствие `transition: all` и наличие `prefers-reduced-motion`;
- проверь CSS-синтаксис доступным инструментом;
- проверь ширины `320px`, `768px`, `1440px`, если доступен браузер;
- убедись, что интерактивные элементы не скрыты, не перекрыты и не стали недоступными;
- если браузерная или синтаксическая проверка недоступна, так и напиши.

Не говори «готово», если проверка провалена или остался непроверенный критический пункт.

## Формат отчёта

Если всё проверено:

```text
✅ Внешний вид обновлён; логика не менялась.
Изменены: <только CSS-файлы>
Что изменилось: <палитра, типографика, тени, переходы, состояния, адаптивность>
Проверено: <diff, CSS-синтаксис, фокус, reduced motion, доступные ширины>
Оговорки: нет
```

Если есть блокер или непроверенный пункт, начни с `⚠️` или `❌`, назови его прямо и не выдавай результат за полностью готовый.
