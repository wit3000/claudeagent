# Чек-лист качества вёрстки

Прогоняй перед сдачей любого архетипа. Каждый пункт — проверяемый; если проверка
недоступна (нет браузера/инструмента), так и напиши в отчёте, а не выдавай за
проверенное.

## Семантика и структура

- [ ] Семантическая разметка: заголовки по иерархии (один `h1`), списки/кнопки/
      ссылки — своими тегами, landmark-элементы (`header`/`main`/`nav`/`footer`).
- [ ] Интерактивные элементы доступны с клавиатуры, порядок табуляции логичен.

## Адаптив

- [ ] Проверено на **320 / 768 / 1440**: нет горизонтального скролла, обрезки
      текста и выхода элементов за контейнер.
- [ ] Важный контент не скрыт и не переставлен ради декора на мобильном.

## Типографика

- [ ] Базовый размер текста **≥16px**.
- [ ] **Кириллица во всех шрифтах**: у каждого шрифта в стеке есть фолбэк,
      покрывающий кириллицу (сериф→сериф, санс→санс); основной шрифт подключён с
      кириллическим сабсетом, если контент на русском.
- [ ] **≤4 размеров текста** на одном экране.
- [ ] Длина строки основного текста **< 70–80ch**.

## Цвет и контраст

- [ ] Контраст **AA**: 4.5:1 для основного текста, 3:1 для крупного.
- [ ] **Один основной акцент**; остальное — нейтрали и семантика.
- [ ] Цвет — **не единственный сигнал** состояния (ошибка/успех/выбор
      дублируются текстом, значком или формой).

## Фокус и моушн

- [ ] Видимый **`:focus-visible`** у всех интерактивных элементов (фокус не
      убран).
- [ ] **`prefers-reduced-motion`** отключает или сокращает анимации/переходы.
- [ ] Переходы — **только по конкретным свойствам** (`color`, `background-color`,
      `border-color`, `box-shadow`, `transform`), никогда `transition: all`.
- [ ] Нет бесконечных/мигающих/укачивающих анимаций без причины.
